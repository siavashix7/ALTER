# ALTER AI OS

ALTER is a fully functional, mobile-first, bilingual (English & Persian) AI Assistant OS built as a Progressive Web App (PWA) with native Android APK packaging.

## 🚀 How to Access

Since this repository is automatically built, you can access ALTER in two ways directly from your Android phone:

### 1. Web App (PWA)
1. Go to the live URL: [https://siavashix7.github.io/Alter-ai/](https://siavashix7.github.io/Alter-ai/)
2. Open your browser menu and tap **"Add to Home screen"** to install it as a fullscreen app.

### 2. Native Android APK
1. Go to the [Actions tab](https://github.com/siavashix7/Alter-ai/actions) in this repository.
2. Click on the latest successful workflow run for "Deploy and Build APK".
3. Scroll down to the **Artifacts** section and download the `ALTER-Android-APK` zip file.
4. Extract the zip on your phone and install the `app-debug.apk` file.

# سیستم عامل هوش مصنوعی آلتر (ALTER AI)

آلتر یک دستیار هوشمند، دوزبانه (فارسی و انگلیسی) با تمرکز بر موبایل است که هم به عنوان یک وب‌اپلیکیشن پیشرو (PWA) و هم یک فایل نصبی اندروید در دسترس می‌باشد.

## 🚀 نحوه دسترسی

از آنجا که این مخزن به‌طور خودکار ساخته می‌شود، می‌توانید مستقیماً از گوشی اندرویدی خود از طریق دو روش زیر به آلتر دسترسی پیدا کنید:

### ۱. وب‌اپلیکیشن (PWA)
۱. به آدرس زنده مراجعه کنید: [https://siavashix7.github.io/Alter-ai/](https://siavashix7.github.io/Alter-ai/)
۲. منوی مرورگر خود را باز کرده و روی **"افزودن به صفحه اصلی"** (Add to Home screen) ضربه بزنید تا به عنوان یک برنامه تمام‌صفحه نصب شود.

### ۲. فایل نصبی اندروید (APK)
۱. در این مخزن به تب [Actions](https://github.com/siavashix7/Alter-ai/actions) بروید.
۲. روی آخرین اجرای موفق با عنوان "Deploy and Build APK" کلیک کنید.
۳. به بخش **Artifacts** در پایین صفحه بروید و فایل فشرده `ALTER-Android-APK` را دانلود کنید.
۴. فایل فشرده را در گوشی خود استخراج کرده و فایل `app-debug.apk` را نصب نمایید.

## 🛠️ Features

- **Multi-Provider AI:** Supports Google Gemini (`gemini-2.5-flash`), OpenAI (`gpt-4o-mini`), and custom endpoints.
- **Memory Vault:** Autonomously remembers personal facts.
- **Task Matrix:** Automatically adds reminders from chat.
- **Voice Capabilities:** Web Speech API for voice input and spoken responses.
- **Local Persistence:** All memory, chat logs, and API keys are stored securely in your browser's local storage. No data is sent anywhere other than the API provider you configure.
